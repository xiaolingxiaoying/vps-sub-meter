# 固定目录读取同代证书和密钥
Status: resolved

Linux 目录交换能保持磁盘成对提交，但两个独立路径读取仍可能跨越提交时刻。固定目录句柄后相对读取两份常规 PEM，拒绝链接和非文件，结合既有 TLS reload stamp 前后检查；增加交错与读取回归。

## Answer

固定主机目录并打开两个常规文件描述符后读取，已打开的读句柄可跨越交换及旧目录清理。若清理先发生，只有暂时 NotFound，不接受混合代。TLS stamp 加入目录设备/inode；相同 mtime、新代替换、并发读取以及旧内存证书回退均有回归。VPS 产物的失败后 TLS 重启和外部订阅正常。详见 [验收记录](../verification.md)。
