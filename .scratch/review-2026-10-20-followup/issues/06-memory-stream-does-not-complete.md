# P1：观测接口读取 memory 数据流一直等待连接关闭

Status: resolved

VPS 验收候选 `60c61d1` 时发现：真实 sing-box 1.14.2 的 `/memory` 是 HTTP chunked 连续快照流。原代码 `read_to_end` 等待 EOF；每次快照又重置套接字的空闲读取超时。因此启用观测接口后的命令一直等待，此次增加的事务锁也被长时间持有。

第一次候选在启用接口时触发 100 秒外层测试超时。测试脚本随后恢复备份，并验证全部原文件/权限、定时器和公网订阅。

## Comments

修复为解析 HTTP 响应头及 chunked 编码，读取首个完整 JSON 值即可返回，同时对整个读取过程施加总期限。新增回归验证连接保持打开时仍能返回跨 chunk 的 JSON 快照，以及持续有字节到达也不能延长总期限。修复后重新进行 Actions 构建和 VPS 验收；未发布失败的候选。
