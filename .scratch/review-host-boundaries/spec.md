# 隔离根目录、失败回滚与进程诊断

目标：非生产 `--root` 不得在缺少命令替身时调用宿主机的服务、账户、证书、防火墙或内核设置命令；工件发布失败只能恢复参与事务的状态，不能删除或重写未参与更新的活动配置。

1. 用每子进程独立的 PATH 替身复现，不更改宿主机真实服务、账户或内核。
2. 复用一个命令解析边界，保持 `/` 的真实主机行为和隔离目录中已提供的替身行为。
3. 用文件大小限制制造真实写入错误，证明错误发生在快照读取后，并验证仅工件更新失败时保留活动配置。
4. 增强上轮偶发观测测试的错误诊断；若不能可靠复现，保持未解决状态，不用重试包装掩盖未知问题。
5. 本地 Linux 门禁后通过 Actions 构建 v0.0.17，用授权 VPS 验证生产产物、签名更新、订阅和五协议转发，全部通过再发布。
