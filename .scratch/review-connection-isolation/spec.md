# 订阅连接隔离与覆写策略校验

目标：单个来源的未完成请求不能占用所有订阅/ACME连接；错误的覆写规则策略必须显式失败。

- 现有全局 32 连接、HTTP 头/握手/连接期限保留，为直连 HTTP、TLS 和 ACME 增加每来源最多 8 个活动连接，在握手/读请求头之前生效。
- 外部反向代理模式保留全局限制，不按后端看到的代理地址限制；来源隔离由前置代理负责。
- 连接完成、失败、取消或超时均释放来源计数；IPv4 映射地址与 IPv4 地址共享计数。
- `rules_mode` 缺省时仍为 prepend；显式值仅接受 prepend/append/replace，JSON 与 YAML 一致。
- 先用旧代码复现，修复后运行 Linux 门禁、GitHub Actions，通过 Actions 生产二进制在 VPS 隔离环境和真实服务上验证，保留恢复机制后发布 v0.0.16。
