# 03 实现运行时 JSON/YAML 模板

Status: ready-for-agent
Type: task
Blocked by: 01, 02

## 工作

实现有界文件读取、模板快照、结构/schema 校验、内置缺省与显式错误。改造 baseline、template 策略目录和渲染器，让约定的 DNS、TUN、路由、规则来源、已有类型代理组布局和测速设置可以外置调整，移除对外部模板的 unwrap/expect 假设。

通过结构化节点注入与版本适配保留凭据边界；服务端模板限于基础设置，不能覆写托管入站凭据。沿用客户端覆写优先级、裸节点/URI 契约和受管文件系统边界。定义配置项与模板冲突时的优先级，不能用硬编码无提示覆盖管理员可调字段。

提供模板导出/校验及应用底层能力。仅改客户端模板时不重启数据平面，不在订阅请求中解析用户文件，不增加文件监听常驻进程。升级保留自定义文件。

## 验收

- 同一 sbctl 二进制修改模板后能生成不同 DNS、路由、代理组结果，无需重编译或重启服务。
- 无外部模板保持默认输出；外部文件非法、缺必要引用、过大或不兼容均不替换已发布产物。
- 真实生成与检查使用同一份已加载快照；客户端版本适配和最后覆写顺序可验证。
- 运行时模板 schema 管理字段不会泄漏到内核配置；权限、符号链接与凭据保护测试通过。
