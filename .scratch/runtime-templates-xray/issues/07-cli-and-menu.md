# 07 内核菜单、模板入口与旧命令兼容

Status: ready-for-agent
Type: task
Blocked by: 03, 06

## 工作

增加 core 子命令与内核管理菜单，提供 list/status、install/update、switch 的只读预览和应用、rollback、logs。最终参数名依据现有 clap 约定确定，帮助文本明确区分内核种类切换、同内核版本更新和客户端模板切换。

交互切换先展示目标版本、保留/停用协议、不可迁移覆写和功能、预计短暂中断。只有显式选择才能停用不支持项；非交互须明确停用列表。模板入口提供导出默认、校验、应用，并显示外部来源与内置默认。旧 sbctl sing-box 与 --sing-box-bin 入口保留明确作用，不能在 Xray 模式误操作当前服务。

状态区分已安装与当前活动内核。基础日志/状态统一，Clash 专属连接操作在 Xray 模式报告不可用及原因，不伪造 gRPC 等价实现。

## 验收

- 数字菜单、取消、默认拒绝不兼容切换、非交互错误码及帮助文本有 CLI 验收。
- 预览不下载或写入部署、不停止服务、不打印凭据；应用复用 06 的唯一事务入口。
- 旧安装、菜单与管理命令通过兼容测试，模板应用明确说明无需编译和客户端刷新步骤。
