# 06 内核切换事务、证书权限与故障恢复

Status: ready-for-agent
Type: task
Blocked by: 03, 04, 05

## 工作

实现只读切换 plan 与实际激活事务。预检支持矩阵、显式停用列表、服务端覆写、Clash API、Hy2 跳跃规则、托管 unit 所有权、端口和证书读取权限。目标检查完成前不得停旧服务；已停止旧服务占用的自有端口应作为合法交接处理。

在操作锁内持久化事务阶段与私有快照，扩展现有受管文件事务而非旁路写文件。覆盖二进制、活动配置、unit/启用状态、订阅、部署配置、证书授权与工具拥有的防火墙状态。实现明确提交点、失败回滚、关键阶段进程中断恢复与手动恢复最近部署的规则；过期快照不得静默覆盖后续修改。

Xray 非 root 运行，证书发布/续期钩子重启当前内核；不接管第三方服务。切换不改 accounting state、不重启订阅服务；完成后只启用目标数据平面，保留可恢复的旧版本。

## 验收

- 同端口双向切换成功，共同节点凭据不变；未支持项在停服务前拒绝。
- 配置检查失败、目标启动退出/重启循环、权限不足、后续发布失败恢复旧服务。
- 在停旧服务后、启动目标后、发布提交边界注入进程中断，恢复命令能识别状态并恢复一致部署。
- Debian/Ubuntu systemd 验证独立非 root 账户、权限、证书续期、Hy2 nftables 残留清理、卸载归属与手动 rollback。
- 订阅旧产物持续可读，流量周期、修正值与凭据宽限状态未重置。
