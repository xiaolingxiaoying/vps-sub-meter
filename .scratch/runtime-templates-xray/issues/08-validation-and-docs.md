- Xray 两个协议均完成实际客户端连接；非 root、证书续期、双向切换和恢复通过。
- 用户能按文档完成模板修改、校验、应用、内核预览、切换与恢复。
- 列出剩余限制；准备可审阅的变更与发布材料，不自动提交、推送或发布。
