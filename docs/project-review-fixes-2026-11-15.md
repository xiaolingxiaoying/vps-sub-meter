# 项目审查修复记录

日期：2026-11-15。范围：当前服务端工作区，包含审查时已有的未提交变更。本记录描述本轮修复与本地验证，不代表生产部署或正式发布验收。

| 审查项 | 修复行为 |
| --- | --- |
| 历史回滚配置不一致 | 恢复节点、客户端批次及白名单内的部署设置；保留最新订阅凭据、账期与流量状态；恢复后重新准备证书访问权限。恢复前校验节点与恢复配置的兼容性。 |
| 开机恢复丢失服务状态 | 恢复原 enabled 状态，在恢复 oneshot 内使用非阻塞服务启动，避免依赖顺序死锁；删除新建服务之前先移除启用链接。 |
| Hy2 范围修改未应用 | 提交候选配置后、启动服务前同步 nftables；范围变化即使不重启内核也会更新规则；失败恢复旧规则。清理路径不依赖完整配置或节点仓库。 |
| 多 Hy2 URI 共用跳跃范围 | URI、Base64 URI、Shadowrocket 和结构化客户端均按节点基础端口决定跳跃设置，复制节点保留自己的独立端口。 |
| ACME 发布临时不安全配置 | 签发期间只暂存订阅监听器配置，并写入可恢复事务；节点仓库、代理配置和公开客户端批次保持原提交，成功后才发布最终配置。 |
| 组策略无效 | 保留“代理”和“自动选择”两个组；select 默认第一个兼容节点，urltest 默认自动选择。管理员覆写仍最后应用。 |
| 订阅批次持续积累 | 每次应用开始前清理五分钟前的无引用批次；保护当前指针、历史恢复点和未完成事务引用；Linux 清理固定到目录句柄，不递归或跟随链接。 |
| 预览创建私钥 | 渲染与计划只描述证书路径，证书生成移到操作锁内的实际应用阶段。 |
| 验证文档过时 | 重写服务端构建指南，移除旧仓库及已拆分客户端的构建目标，区分常规测试、固定内核及真实 systemd 验收。 |

## 本地验证

- 新增 [managed_recovery.rs](../tests/managed_recovery.rs) 的 10 项回归，覆盖回滚、开机排队、Hy2 更新与失败恢复、组默认值、预览、ACME 中断以及订阅清理与链接边界；WSL 全部通过。
- 新增 CLI ACME 成功和失败场景，签发脚本检查原节点、代理配置与批次未被替换，并验证最终客户端启用证书校验；通过。
- WSL 工作区常规测试及新旧菜单伪终端验收通过；普通构建的开发签名拒绝测试通过。
- Windows 的六项可跨平台恢复回归通过；Windows、WSL 的格式与全部目标/特性 Clippy 检查通过。
- 托管真实内核矩阵、sing-box 到 Xray 的 VMess 转发、Xray 服务端配置检查通过。使用本机固定 sing-box 1.10.7、1.11.15、1.12.25、1.13.21、1.14.1、Xray 26.10.31 和 Mihomo 工件。
- 五项安装器 Python 测试、订阅页复制交互检查、补充的 systemd 验收脚本语法检查通过。
