# 隔离目录的命令边界与活动配置回滚范围

## 问题

`Runtime::live` 原先把“使用真实时钟”同时解释为“可以回退宿主机命令”，即使其根目录不是 `/`。服务生命周期又有各自的 systemctl 和账户命令回退。隔离目录缺少替身时，重启、BBR、证书续期和防火墙操作可能作用于宿主机。

仅工件重新生成的失败回滚还把“未读取活动配置快照”解释成“活动配置此前不存在”，导致删除原本不参与更新的文件。

## 决策

- Runtime 统一解析服务、账户、证书、防火墙、内核设置与观测命令。非 `/` 的根目录只接受该目录下 `usr/bin` 或 `usr/sbin` 提供的命令；缺少替身时明确失败。只有真实 `/` 操作保留宿主机 PATH 回退。真实时钟不再授予宿主机命令权限。
- 命令必须是单一程序名；拒绝绝对路径、目录分隔符、`.` 和 `..`。明确传入的 sing-box 二进制及始终携带目标根目录的归档工具不在该接口内。
- 工件回滚显式区分活动配置 `Untouched` 与 `Restore`。在活动配置写入前发生错误时，不读取、不删除、不重写该路径；只有尝试写入活动配置后才使用其快照恢复。该规则同时用于 regenerate 和配置事务。
- 该目录适配器用于受信任的测试替身和镜像准备，不是 chroot，也不负责隔离替身自身的任意系统调用。

## 验证

回归测试用子进程独立 PATH 替身观察是否跨出隔离目录，不调用真实宿主机服务或 sysctl。另在检查完成后降低 sbctl 子进程的文件大小限制，制造真实写入失败，覆盖回滚不能删除活动配置的情况。发布仍要求真实 systemd 和 VPS 验收。
