# 代码审查修复（2026-10-20）

本轮修复基于 `66e2fca`，不改变部署配置结构，不轮换现有凭据。

## 修复

1. **P1：过期配置向导恢复旧订阅凭据。** 全量向导和菜单专题向导在提交时，持操作锁比较起始配置与最新配置。有冲突即退出 2，提示重新打开向导。锁一直保持到生成、服务激活、失败恢复和账期状态重建结束，避免回滚覆盖其他终端或定时任务的更新。初始化、客户端模板切换和账期重建增加持锁调用路径，避免重复获取同一把锁。
2. **P2：远程二进制规则集混用。** `.srs` 仅写入 sing-box 完整订阅；`.mrs` 仅写入现行 Mihomo。规则集声明、路由引用及旧版 block outbound 同步过滤。需要相同策略覆盖两端时分别注册两个名称及其对应格式 URL。minimal 和 Mihomo 1.18 继续不加载远程集。CLI 注册结果提示目标客户端，使用指南已更新。
3. **P2：fake-ip 例外遗漏精确域名与关键词。** 后缀保留原位扩展；精确域名、关键词各用独立 DNS 规则，排在 fake-ip 通配规则之前，避免不同匹配条件相交。fake-ip 列表不接受 IP-CIDR，CLI 写入和手工文件加载都会明确报错。
4. **P3：刷新间隔整数溢出。** 使用安全乘法并限制为正数及 Go Duration 可表示范围；非法 Unicode 单位也不会触发字节切片 panic。CLI 与持久配置校验共用同一解析器，拒绝发生在配置写入前。
